# Icons

The outline icons in this folder are drawn on a shared 24-unit grid.
`metrics.js` records their visible ink, measured at build time.

Service logos are not part of the source. A personal icon set can be placed in
`.local/personal/overlay/assets/icons/` together with a matching `metrics.js`;
the preview and the owner's package layer it over this folder. Apps without a
logo use the icon provided by the TV, or their initials.
