# Wallpapers

Each entry in `SOURCES.json` has a 1920×1080 background, a thumbnail and a small
blurred panel backdrop. Its four glass materials live in `../materials/`.
`catalog.js` holds names and surface settings used by the interface.

Photographers and licences are listed in [docs/credits.md](../../../docs/credits.md).
How the materials are generated is described in [docs/development.md](../../../docs/development.md#wallpapers-and-glass).
